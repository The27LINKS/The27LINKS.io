How to Use the CRAB Asset Verification Engine?

The Crab Asset Discovery Tool engineered by The27LINKS allows data administrators, database architects, and system analysts to sequentially trace asset availability. By building Cartesian product matrices across multiple dynamic variable parameters (such as serial ranges, batch timelines, or custom string lists), users can verify that live server links align directly with database entries without freezing browser frames.

Configuring Variable Tokens

To use multiple variable sequences, configure your URL template string with clean brackets containing the variable tokens, such as {variable1} or {variable2}. The tool will parse each node type sequentially:

  • Numbers Sequence: Generates progressive loops from a minimum range bounds value directly up to a maximum parameter scale. Optional string zero-padding turns numbers like 45 into fixed structures like 000045.
  • Letters Array: Loops incrementally through customized typographic standard characters constraints (e.g., matching alphabetic strings from a to z).
  • Space Separated Array: Allows direct entry of custom lists separated by empty spaces. The engine splits these list strings instantly to test varying combinations.
