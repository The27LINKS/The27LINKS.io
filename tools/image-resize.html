How to Resize an Image Correctly

  • Keep Aspect Ratio Checked: Unless you want your image to look stretched or squished, always leave the "Keep aspect ratio" box checked. If you type a new Width, the Height will automatically adjust to keep the photo looking natural.
  • Percentage Mode: If you don't know exact pixels but know the file is way too big, switch the Mode to "By percentage" and type "50" to instantly make the image half its original size.
  • Standard Web Sizes: For most blogs, articles, and websites, an image width between 1200px and 1600px is optimal. Anything larger is generally wasted bandwidth.

Frequently Asked Questions

Will resizing my image reduce the file size?

Yes! If you scale down the pixel dimensions of an image (for example, from 4000px wide to 1000px wide), the overall file size in megabytes will drop significantly. For even smaller file sizes, try passing your resized photo through our Image Compressor.

Can I make a small image bigger?

You can, but it is generally not recommended. Standard image formats (JPG, PNG) are made of pixels. If you take a small image and stretch it to be larger, the browser has to invent new pixels to fill the space, which usually results in a blurry or "pixelated" image.
